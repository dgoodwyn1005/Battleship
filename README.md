⚓ Battleship Game (Pygame)

A recreation of the classic Battleship game built using Pygame as part of a
Software Engineering course project (Fall 2024).

This project emphasizes Object-Oriented Programming (OOP) concepts such as class design, encapsulation, and separation of game logic, UI, and data handling.

![Screenshot](/screenshots/home)

**Game Features**
Classic Battleship Gameplay

Follows standard Battleship rules

8 × 8 grid layout
Turn-based play against a CPU opponent


![Screenshot](/screenshots/)

CPU Opponent

  -Automated ship placement
  -Computer-controlled attack logic
  -Designed to simulate a traditional Battleship experience


![Screenshot](/screenshots/gameplay)

Win / Endgame Screens

  -Displays victory or defeat outcomes
  -Signals game completion clearly to the player
